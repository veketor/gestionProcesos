# Cronograma de procesos · Sistemas Operativos Monopuesto (1º SMR)

Web didáctica para explicar y practicar la **planificación de procesos**:

- Multidioma: **español** / **inglés** (textos + viñetas)
- Tutorial visual estilo cómic (anterior / siguiente), con diapositivas de cronograma y apropiativo / no apropiativo
- Algoritmos: **FCFS / FIFO**, **SJF**, **SRTF**, **Prioridad** (no apropiativo y apropiativo), **Round Robin**
- Generador-corrector con cronograma **E / L / F**, marcas de **llegada**, fila **Cola** y corrección parcial

## Cómo abrirla

En local: Abre `index.html` en el navegador (doble clic o Live Server).

No requiere instalación ni servidor.

Está disponible también en github pages.

## Uso del corrector

1. Elige el algoritmo (tarjetas o desplegable; quantum si es Round Robin).
2. **Generar nuevo** (sin repetir en la sesión) o **Ejemplo fijo**.
3. Rellena celdas con clic (vacío → E → L → F). Si un proceso llega y espera, usa **L** desde ese instante (▼ en el eje indica llegadas).
4. Escribe la cola (un proceso por línea).
5. Completa comienzo, fin, retorno, espera y promedios.
6. **Corregir mi respuesta** (marca errores y explica dónde) o **Ver solución**.

## Leyenda

| Símbolo | Significado                           |
| ------- | ------------------------------------- |
| **E**   | Ejecución en la CPU                   |
| **L**   | En espera de CPU: ha llegado y espera |
| **F**   | Finalizado (instante de fin)          |

Prioridad: **número más bajo = más prioritario**.  
FCFS = FIFO (First In, First Out).
